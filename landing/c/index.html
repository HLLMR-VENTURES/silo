What happens when you open it: Silo shows a preview first: what you already have, what it can install, and what you need to get from ModHub yourself. When you import, it downloads the mods it can install directly (GitHub releases), checks each download against the build the sharer pinned when the collection includes one, and saves the set as a loadout. Downloaded mods land in your mods folder like any new download; the rest of your active set changes only when you apply that loadout. No mod files are transferred through this page; it's just the list. View the source on GitHub.
