The Silo catalog

One record per mod. Two sources. Checked against the published build.

Silo aggregates ModHub and GitHub into a single canonical record for each Farming Simulator 25 mod — with the latest version found across both — and hashes each build from its source, so an installed mod can be checked against the build its source published. This is the engine behind Silo's catalog and its Verified badge.

Why it exists

Mods scatter. The truth gets fuzzy.

A mod lives on ModHub, its author ships newer builds on GitHub. Which is the latest? Is the file you downloaded the one the author actually published — or was it repacked with something extra? The catalog answers both.

⌗

One canonical record

A mod's ModHub and GitHub listings are resolved to a single record, so you see the latest version found across both.

✓

Provenance, not antivirus

We hash published builds. Silo hashes your installed copy on your computer and compares: a clean match, or the exact files that differ. It confirms what a mod is. It doesn't guess intent.

⟳

What's covered

An hourly job refreshes versions and metadata, most popular mods first. New hashed builds currently come from GitHub releases. ModHub hashing is paused, so only ModHub versions we already hashed can be verified.

✓ Verified ◐ Modified ? Unverified — the three verdicts you'll see in the app, and on Browse.

Silo indexes public mod information and links back to each source. It does not host, mirror, or redistribute mod files. Downloads always go to the original source, whose own terms apply. Our catalog server keeps cached copies of cover images and the file hashes it computed for integrity checks.

For mod authors

Help us get your builds right.

Provenance is only as good as its source of truth, and no one knows a mod's real build better than the person who made it. We'd like mod authors to be able to confirm their own builds, so the ✓ Verified check uses the files you published. There's no way to do that yet.

  • When Silo has your published build on file, players can check whether their copy matches it.
  • If your mod is listed wrongly, or you'd rather it wasn't listed, tell us and we'll fix it.

Interested? Open an issue on GitHub or email legal@hllmr.com.

For developers

A public read API.

The catalog is served by SiloAPI — a public, read-only HTTP API. No key, no account. Please be a good citizen (it's rate-limited); it aggregates public metadata and links back to sources.

Base: https://silo-api.hllmr.com

GET /stats GET /categories GET /mods?q=&category=&sort=&limit=&offset= GET /mods/:id GET /mods/:id/manifest?version= POST /mods/lookup GET /facets GET /img/:id

The Browse page is built entirely on these endpoints — view its source for a working example.
