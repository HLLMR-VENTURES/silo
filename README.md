# Silo showcase screens, v1

Screenshots for silo.hllmr.com, made with the showcase kit (`scripts/showcase/`; how to re-run it
is in `docs/SHOWCASE.md` once HLLMR/silo#267 lands). The real app, running a debug build against
a fictional ~700-mod demo library: every mod, author, map and account shown is made up.

- 3200×2000 PNG each: a 1600×1000 page at 2×, dark theme, **no window frame** (the site draws it).
- `alt.json`: one short alt line per file.
- Home: `library`, `crash-notice`, `diagnose-last-run`, `find-problem-mod`, `conflicts`,
  `verified-build`, `modified-build`, `mod-sets`, `share-set`, `updates`, `browse`.
- Help: `help-mods-folder`, `help-organize-preview`, `help-undo-organizing`, `help-savegames`,
  `help-mp-check-file`, `help-filltype-bridge`, `help-bindings`, `help-accounts`,
  `help-copy-diagnostics`. Library archive move (in progress) isn't included.

This branch holds images only. Don't merge it into `main`.
